WolfDbg v0.5.0 — BUILD AND INSTALL

1. Extract this ZIP (it contains a WolfDbg directory).
2. cd WolfDbg
3. export JAVA_HOME=/usr/lib/jvm/java-21-openjdk-amd64
4. export PATH="$HOME/gradle-8.13/bin:$PATH"
5. gradle clean :app:assembleDebug --no-daemon
6. adb install -r app/build/outputs/apk/debug/app-debug.apk
7. adb shell monkey -p com.scarface.reverse.v4 1

If the launch fails, check the real package using:
adb shell pm list packages | grep scarface

The app ID is com.scarface.reverse.v4; the displayed label is WolfDbg.
